# Dahan — Offline-First Habit & Quit Tracker
**Dahan** is a calm, privacy-first Android app for building daily/weekly routines and quitting unwanted habits—without guilt-trip streaks, accounts, or paywalls.
- **Try the Live Web Demo:** https://dahan-app.pages.dev/
- **Download Latest Android APK (v0.1.0 · 3.2 MB):** https://github.com/L4wrenzzz/dahan-releases/releases/download/v0.1.0/dahan-v0.1.0.apk
## Highlights
- **100% offline & local:** All data stays on your device (IndexedDB via Dexie)—zero accounts, zero tracking, zero network calls.
- **No-guilt design:** Tracks daily streaks alongside total completions, plus a quit tracker with fresh-start logging and a 30-day visual heatmap.
- **Data ownership:** Export and restore your full history anytime via validated JSON backups.
- **Built with:** React, TypeScript, Vite, Capacitor, Dexie, and Vitest (218+ unit tests).
## How to Install on Android (Sideload)
1. Download `dahan-v0.1.0.apk` from the link above.
2. Open the file and allow **"Install unknown apps"** when prompted by Android (Play Protect may show a standard warning for sideloaded apps).
3. To keep your habits safe across future updates or phone changes, use **Settings → Export data** regularly.
